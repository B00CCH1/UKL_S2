================================================================================
                    UKL API - QUICK REFERENCE
================================================================================

BASE URL: http://localhost:3000/api

================================================================================
1. AUTH - REGISTER CLIENT
================================================================================
POST /api/auth/register

Headers:
  Content-Type: application/json

Body:
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "password123"
}

Response (201):
{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com",
  "role": "client",
  "createdAt": "2026-06-03T10:30:00.000Z"
}

================================================================================

4. PRODUCTS - GET ALL
================================================================================
GET /api/products

Query Parameters (optional):
  search=laptop           - Cari produk
  minPrice=100           - Harga minimum
  maxPrice=5000          - Harga maksimum
  minStock=5             - Stok minimum
  maxStock=50            - Stok maksimum
  sortBy=createdAt       - Field sorting (default: createdAt)
  sortOrder=desc         - asc/desc (default: desc)
  limit=10               - Jumlah data (default: 10)
  page=1                 - Halaman (default: 1)

Example:
  GET /api/products?search=laptop&minPrice=100&maxPrice=5000&page=1&limit=10

Response (200):
{
  "data": [
    {
      "id": 1,
      "name": "Laptop Gaming",
      "description": "High performance gaming laptop",
      "price": 1500,
      "stock": 10
    }
  ],
  "pagination": {
    "total": 1,
    "page": 1,
    "limit": 10,
    "totalPages": 1
  }
}

================================================================================
6. PRODUCTS - UPDATE
================================================================================
PUT /api/products/:id

Headers:
  Content-Type: application/json

Example: PUT /api/products/1

Body:
{
  "name": "Mouse Wireless Pro",
  "description": "RGB wireless mouse with 72h battery",
  "price": 75,
  "stock": 15
}

Response (200): Updated product object

================================================================================
7. PRODUCTS - DELETE

}

================================================================================
8. TRANSACTIONS - CREATE
================================================================================
POST /api/transactions

Headers:
  Content-Type: application/json
  Authorization: Bearer YOUR_TOKEN_HERE

Body:
{
  "productId": 1,
  "quantity": 2
}

Response (201):
{
  "id": 1,
  "userId": 1,
  "productId": 1,
  "quantity": 2,
  "totalPrice": 3000,
  "product": {
    "id": 1,
    "name": "Laptop Gaming",
    "price": 1500
  }
}

================================================================================
IMPORTANT NOTES
================================================================================

1. Token Requirements:
   - Endpoints yang butuh Authorization: POST /transactions, GET /transactions/my
   - Dapatkan token dari endpoint LOGIN
   - Format: Authorization: Bearer TOKEN

2. Content-Type:
   - Semua request harus: Content-Type: application/json

3. Status Codes:
   - 200: OK
   - 201: Created
   - 400: Bad Request
   - 404: Not Found
   - 500: Server Error

4. CORS:
   - API allow origin: http://localhost:3000

5. Admin Secret:
   - Default: admin_secret_key_123
   - Ubah di .env file
